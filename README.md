## 🎒 Project Overview
This project is an authentic, human-crafted **Grade 7 Science Project** built for a single-screen viewport without long scrolling.

- **✏️ Authentic Anatomical Pencil Sketch Drawing**:
  - Direct pencil illustration of the digestive system within the outline of the human body (based on NIDDK Media Asset #17996).
  - Features an animated 10-second pencil drawing effect with interactive clickable label pins:
    * Esophagus, Stomach, Liver, Gallbladder, Pancreas, Duodenum, Small intestine, Large intestine, Appendix, Rectum, Anus.
  - Paper Mode & Chalkboard Mode toggle.
- **✨ Instant AI Organ Search Box**:
  - Quickly search any organ (Stomach, Liver, Esophagus, Pancreas, Heart, Femur) for immediate primary function and science facts.
- **🎯 1-Click Systems Drill-Down**:
  - Drill into 6 major systems with short, punchy facts and key anatomical features.
- **📱 Built-in QR Code**:
  - Tap the QR Code button at the top to scan and view on any mobile device.
