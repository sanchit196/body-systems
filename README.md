## 🎒 Minimalist Philosophy
Instead of endless scrolling, bloated paragraphs, or generic AI renders, this project is built for **instant understanding on a single screen**:

- **🖤 Pure Black Aesthetic**: Deep matte black dashboard (`#09090b`) with high-contrast text and crisp typography.
- **✏️ 10-Second Pencil Sketch Animation**: A live-animated human anatomical pencil sketch that draws itself in a 10-second loop with an animated pencil cursor.
- **✨ Instant AI Organ Search Box**: Type any body part (Heart, Femur, Alveoli, Kidneys, Brain) for immediate definition, function, and automatic body localization.
- **🎯 1-Click Systems Drill-Down**:
  - Click any Body System (Circulatory, Respiratory, Nervous, Digestive, Skeletal, Excretory).
  - Open its key body parts.
  - View short, bite-sized primary functions and science facts with zero clutter!
- **📱 Instant QR Code**: Tap the QR button to display the modal for instant phone scanning.
